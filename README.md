how to run the project

1. create the database and table which is mention in database folder sql file
2. create .env file in backend folder just like i have show in .env.example
3. then go to backend folder and install node_modules using command 
    "npm install"
4. also go to frontend folder and install node_modules using comman 
    "npm install"

5. run backend with command
    1. node app.js
    or
    2. npx nodemon app.js

6. also run front with command
    npm run dev

7. go to 
    http:localhost:5173
